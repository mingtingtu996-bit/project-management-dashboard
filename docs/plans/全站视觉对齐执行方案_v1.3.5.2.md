# WorkBuddy 全站视觉对齐执行方案 v1.3.5.2

## Context

v1.3.5.1（Dashboard 视觉精修 + 重构）已形成样板页面。本方案将 Dashboard 确立的设计语言、组件模式和实测微调原则推广到全站其余页面，确保用户在页面间切换时视觉体验一致。

**样板来源**：当前 `client/src/pages/Dashboard.tsx` 实现与 `client/src/pages/__tests__/Dashboard.test.tsx` 中的 v1.3.5.1 保护用例。Dashboard 页面级主方案以 `artifacts/视觉精修Dashboard重构执行方案.md` 为准；本文件负责将该样板沉淀为全站规则。

**v1.3.5.1 内部优先级**：Phase 9（实测微调）为最终结论，与 Phase 1-8 冲突时以 Phase 9 为准。具体冲突点：
- KPI 卡片：无弧形 SVG 装饰（9B.1 覆盖 7.1）、内边距 `p-5`（9B.2 覆盖 7.1 隐含的 `pl-14`）
- Sparkline 持平：传 `[50,50,50,50,50]` 水平线（9B.4 覆盖 7.8 的"不渲染"）
- HealthCards donut：`innerRadius="75%" outerRadius="95%" cornerRadius={10}`（9G.2 覆盖 5C 的 `80%/100%/20`）

**约束**：
- 不违反 `UI_UX商业级全面优化方案_v1.3.md` 与 `design-system/workbuddy/MASTER.md` 定下的原则
- 不改品牌色、不改字体、不改页宽
- 本文件是 v1.3 的后续视觉覆盖口径：卡片容器从 v1.3 的 `rounded-xl` 升级为 `surface-card rounded-2xl`；Dialog 仍为 `rounded-2xl`；按钮与 badge 仍遵守 `rounded-lg`
- 前端只做展示映射、排序、筛选、跳转；主指标必须来自后端摘要/周报/健康度/快照服务，具体接线以本文 KPI 接口接线表为准
- 圆角以 `surface-card rounded-2xl` 为准（v1.3.5.1 已确认覆盖旧 `rounded-xl` 卡片口径）
- 表格使用共享 Table 组件，不新建原生 `<table>` 或 `div+grid` 模拟

**从 v1.3.5.1 Phase 9 提炼的全站原则**：
1. Tab 内容区面板化：每个 TabsContent 用单个 `surface-card p-5` 包裹，内部用 `border-b border-slate-100 pb-5 mb-5` 分区
2. 子组件去壳：进入面板容器后，子组件不再自带 `surface-card` / `rounded-2xl border shadow`
3. 状态 pill 统一 `ring-1 ring-inset ring-slate-200/60`（替代 `border`）
4. 进度条统一 `h-[3px] rounded-full`
5. 零值降级：数字 `text-slate-400`，进度条 `Math.max(progress, 4)%`，Sparkline 持平传水平线
6. CardHead 替代手动 CardHeader+CardTitle
7. 语义工具类：`.eyebrow` / `.meta-text` / `.meta-muted` / `.num-display` / `.num-mono`，JSX 不散落 `text-[10.5px]` 等

10. **PageTitle 框架统一**：除 Dashboard 保持 v1.3.5.1 已验收的 `DashboardPageTitle` 外，其余页面采用 Dashboard 的 PageTitle 结构（Breadcrumb → 业务域 eyebrow → 标题 → 操作按钮），通过 PageHeader 组件实现

13. **切换器二分法**：页面级 Tab 用下划线样式，卡片内筛选用 SegmentedControl pill 样式（详见 Phase 0.5）
14. **表格行交互**：可点击行统一 hover 背景 + chevron 箭头 + 进度条微动效（详见 Phase 0.6）

19. **Section header 平铺**：页面内的 section 标题区（如偏差表、风险列表、任务分组等）不用 `surface-card` 卡片包裹，改为平铺在页面背景上（CardHead eyebrow + title + 右侧操作/搜索 + 下方筛选 Tab），与 PageTitle 视觉语言一致（详见 Phase 0.11）

## Phase 0: 全局补充（在页面改造前完成）

### 0.1 新增语义工具类

**文件**: `client/src/index.css`（@layer components）

```css
.meta-text  { @apply text-[11px] text-slate-500; }
.meta-muted { @apply text-[11px] text-slate-400 tabular-nums; }
```

说明：`text-[10px]` / `text-[11px]` / `text-[10.5px]` 只允许沉淀在 `.eyebrow`、`.meta-text`、`.meta-muted`、`.num-mono`、badge 尺寸等语义工具类或共享组件内；业务 JSX 不再散落任意字号。这是 v1.3.5.2 对 v1.3 “消除任意字号”的语义化例外。

### 0.1a 数字字形特性级精修

**文件**: `client/src/index.css`（@layer components）

Figma Make 参考稿里的数字质感不是只靠 `tabular-nums`，而是启用了 OpenType / 可变字体特性。v1.3.5.2 需要升级现有 `.num-display` / `.num-mono`，不要新建另一套数字类。

```css
.num-display {
  @apply tabular-nums tracking-[-0.03em];
  font-feature-settings: 'tnum', 'cv11', 'ss01', 'ss03';
  font-variation-settings: 'opsz' 32;
}

.num-mono {
  @apply tabular-nums;
  font-feature-settings: 'tnum', 'cv11';
}
```

执行约束：
- `.num-display` 不再写死 `font-bold`，字重由调用组件控制；KPI / Stat 大数字统一使用 `font-semibold`，避免全站数字过黑。
- `.num-display` 适用于 KPI 大数字、TrendChart 统计数字、ProgressSection 百分比、Dashboard/CompanyCockpit 等展示型关键数字。
- `.num-mono` 适用于表格数据单元格、日期/周期、百分比小数字、kbd/快捷键提示、对比卡片的小型统计值。
- Dashboard 内遗漏的 `tabular-nums` 裸数字需要替换为 `.num-display` 或 `.num-mono`；表格数字列统一 `text-right num-mono`，日期列统一 `num-mono text-slate-500`。
- 若当前字体不支持 `cv11` / `ss01` / `ss03` / `opsz`，浏览器会安全忽略；不得因此回退到新增私有类或硬编码单页样式。

### 0.4 LucideIcon wrapper 推广

各页面新增或修改的 icon 引用优先使用 `<LucideIcon>`（`client/src/components/ui/lucide-icon.tsx`，默认 `strokeWidth={1.5}`）。不要求一次性全站替换，但本次改造涉及的组件内新增 icon 必须用 wrapper。

### 0.5 切换器样式二分法

Dashboard Phase 9 确立了两种切换器，按场景选用：

| 场景 | 组件 | 样式 |
|------|------|------|
| 页面级大区块切换（Tab） | `<Tabs>` + `<TabsTrigger>` | 下划线：`h-[2px] rounded-full bg-blue-600`，inactive `text-slate-500 hover:text-slate-700` |
| 卡片内小范围筛选 | `<SegmentedControl>` | pill：`bg-slate-100/70 rounded-lg p-0.5`，active `bg-white shadow-[0_1px_2px_rgba(15,23,42,0.06)]` |

各页面按实际场景选用，不混用。当前 v1.3.5.2 各页面 Tab 条目如引用了 SegmentedControl 样式用于页面级 Tab，应改为下划线样式。

### 0.6 表格行交互模式

可点击的列表行 / 表格行统一以下模式（来自 Dashboard FocusTasks 5D + 9I）：

- 行容器：`group border-b border-slate-100 hover:bg-slate-50/60 transition-colors cursor-pointer`
- 行右侧 chevron：`ChevronRight w-3.5 h-3.5 text-slate-200 group-hover:text-slate-500 transition-colors`
- 行内进度条 hover 微动效：默认 `h-[3px]`，`group-hover:h-1`；默认色按状态，`group-hover:bg-blue-500`；transition `200ms ease-out`
- 行内时间标签：`text-[11px] text-slate-400 tabular-nums` 右对齐

适用页面：所有有可点击行的列表/表格（Milestones 里程碑列表、TaskSummary 任务行、AcceptanceTimeline 验收项、PreMilestones 证照行、Notifications 通知行、Drawings 图纸行、CloseoutPage 关账行）。

### 0.7 SectionHeader eyebrow 使用

v1.3.5.1 Phase 5E.1 已给 `SectionHeader` 组件新增 `eyebrow?: string` prop。各页面使用 `SectionHeader` 时应传入业务域 eyebrow（与 CardHead eyebrow 同理），不传时组件行为不变。

### 0.8 表头排序 affordance

可排序表格的表头统一加排序暗示（来自 Dashboard Phase 8.2）：

- 表头 label 旁加 `ChevronsUpDown w-3 h-3 strokeWidth={1.5}`
- 默认 `opacity-0`，hover 整列标签时 `opacity-100`（`150ms transition-opacity`）
- 适用页面：所有使用共享 Table 组件且支持排序的表格

### 0.9 卡片内 footer 模式

有"查看更多"需求的卡片统一 footer 样式（来自 Dashboard Phase 5E.8）：

```
mt-4 pt-3 border-t border-slate-200/60
左侧：计数文本（如"共 {n} 个"），text-[11px] text-slate-400
右侧：操作链接（如"查看全部 →"），text-[11px] text-blue-600 hover:text-blue-700
```

### 0.10 TabsList 无横向滚动

所有页面的 `TabsList` 移除 `overflow-x-auto`（来自 Dashboard Phase 9C.1），确保 Tab 不出现横向滚动箭头。Tab 数量应控制在一行可容纳范围内；如果一行容纳不下，优先合并 Tab、下沉为卡片内筛选或允许换行，禁止挤压文字、裁切 Tab 或重新引入横向滚动。

### 0.11 Section header 平铺（不用卡片包裹）

```

─────────────────────────────────

```

### 0.12 eyebrow 纯文本格式
