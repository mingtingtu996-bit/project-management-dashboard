# Python Data Governance Tools

Pinned optional Python CLIs:

- `datacontract-cli==1.0.9`
- `soda-core-postgres==3.5.6`

Install outside committed source control, for example in a local venv:

```powershell
python -m venv project-data/plugins/python-tools/.venv
project-data/plugins/python-tools/.venv/Scripts/python.exe -m pip install -r project-data/plugins/python-tools/requirements.txt
```

The `.venv` directory should stay untracked.
